TP3 - SPORTIX

Projet web dynamique connecté à Oracle avec ORDS

Ce que on peut faire dans ce projet :

- Afficher les clients
- Ajouter ou supprimer des clients
- Afficher des commandes
- Ajouter et supprimer des commandes
- Recherche des événements par sport ou id

Exécution du projet:

-La VM Oracle doit être lancée
-Ouvrir le terminal dans le dossier ORDS
-Lancer ORDS avec la commande : ords serve --port 8181
(car le port 8080 était déja utilisé)
- Ouvrir le projet avec live Server
